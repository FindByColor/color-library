Development Scripts
===

NPM Scripts:

| command               | description                                          |
|-----------------------|------------------------------------------------------|
| `npm run build`       | Build & Compile Color Library                        |
| `npm run dev`         | Watches for Code Changes and re-runs `npm run build` |
| `npm run lint`        | Tests Javascript Code against Linting Rules          |
